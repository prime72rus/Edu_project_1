# Учебный проект анализа данных

Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.
## SRC
### Модуль utils.py
Содержит вспомогательные функции:  
read_xlsx - функция для считывания финансовых операций из XLSX-файла. Принимает путь к файлу XLSX в качестве аргумента и возвращает DataFrame с банковскими операциями.  
checking_date_from_user - функция принимает на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS, проверяет ее на соответствие шаблону ввода, в случае совпадения возвращает строку в формате YYYY-MM-DD HH:MM:SS.  
selecting_data_by_date - функция принимает на вход DataFrame и пользовательскую дату в формате YYYY-MM-DD HH:MM:SS, осуществляет выборку - это данные с начала месяца, на который выпадает входящая дата, по входящую дату.  
get_greeting - функция возвращает строку приветствия в зависимости от текущего времени суток.  
get_unique_card_number - функция получения уникальных номеров карт.  
calculate_total_expenses - функция для расчета суммы операций по платежам каждой карты.  
calculate_cashback - функция для расчета кешбэк (1 рубль на каждые 100 рублей).  
get_top_operations - функция для получения топ-5 транзакций по сумме платежа.  
get_settings_from_file - функция получения пользовательских настроек из файла user_settings.json.  
api_currency_rates - функция получения курса валют из внешнего API.  
api_convert_currency - функция получения курса USD из внешнего API для конвертации стоимости акций.  
api_currency_stocks - функция получения стоимости акций из внешнего API.  
convert_stock_price - функция конвертации стоимости акций из USD в рубли.  

### Модуль views.py
Страница «Главная»

Реализована главная функция web_site_main, принимающая на вход строку с датой и временем в формате 
YYYY-MM-DD HH:MM:SS и возвращающую JSON-ответ со следующими данными:  
Приветствие в формате "???", где ??? — «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени.  
По каждой карте:  
- последние 4 цифры карты;  
- общая сумма расходов;  
- кешбэк (1 рубль на каждые 100 рублей).  

Топ-5 транзакций по сумме платежа.  
Курс валют.  
Стоимость акций из S&P500.  

### Модуль services.py
Содержит функцию search_translations реализации сервиса: "Поиск переводов физическим лицам"

Функция возвращает JSON со всеми транзакциями, которые относятся к переводам физлицам.
Категория такой транзакции — Переводы, а в описании есть имя и первая буква фамилии с точкой.
Например:  
Валерий А.  
Сергей З.  
Артем П.  

### Модуль reports.py
Содержит функцию spending_by_category создания отчета "Траты по категории" в виде DataFrame.  
Так же модуль содержит декораторы для функции-отчета, которые записывают в файл результат, возвращаемый функцией, формирующей отчет.  
Декоратор без параметра — записывает данные отчета в файл с названием по умолчанию (формат имени файла придумайте самостоятельно).  
Декоратор с параметром — принимает имя файла в качестве параметра.  

### Модуль main.py
Для реализации функционала по запуску приложения.

### .EVN_TEMPLATE
Содержит указание по настройке API-ключей.

### Модуль config.py
Содержит пути к требуемым каталогам и файлам для использования в приложении.

### Файл user_settings.json
Содержит данные пользовательских настроек: список валют и список акций.
